# H3 ShotTools

Endangered AI timing and prompt-validation nodes for Fantastic MiniMax H3.

Clone this repository into `ComfyUI/custom_nodes/ComfyUI-H3-ShotTools`, then restart ComfyUI. Uses ComfyUI's existing Python dependencies. Tested with ComfyUI 0.39.0 and Fantastic H3 PromptBuilder.

Provides seconds-based timing, H3-compatible generation frame counts, canvas presets, and validation of numbered shot prompts.
